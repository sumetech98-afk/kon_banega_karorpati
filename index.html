How to Use / उपयोग कैसे करें

🎯 What is this game?

This is "Kon Banega Karorpati" – a lucky box game where you pick a box and win a prize! Each box has a hidden amount and a unique 4-digit code. You pay ₹25 to open a box and win up to ₹1 Crore. Minimum prize is ₹1000.

📋 Step-by-Step Guide

  • 1. Login / Register – Create an account or login with existing credentials.
  • 2. Select a Box – Click on any box from the 10×10 grid. It will turn gold and show its 4-digit code.
  • 3. Pay & Play – Click "Pick Box & Pay ₹25". You'll see a QR code and UPI ID with your box code.
  • 4. Make Payment – Copy the UPI ID and pay ₹25 using PhonePe, Google Pay, or any UPI app. Mention the 4-digit box code in payment note if possible.
  • 5. Submit Proof – After payment, click "Payment Proof Submit" and fill the form with the box code, transaction ID, and UPI phone number.
  • 6. Win Prize – Admin will verify your payment and reveal your box prize!

📱 Payment Details

  • Amount: ₹25 (fixed)
  • UPI ID: s6154632725482301@slc (change to your own)
  • Box Code: Unique 4-digit code shown on selected box

🎯 यह गेम क्या है?

यह "कोन बनेगा करोड़पति" – एक लकी बॉक्स गेम है जिसमें आप एक बॉक्स चुनते हैं और एक इनाम जीतते हैं! हर बॉक्स में एक छिपी हुई राशि और एक अनोखा 4-अंकीय कोड होता है। आप ₹25 देकर एक बॉक्स खोलते हैं और ₹1 करोड़ तक जीत सकते हैं। न्यूनतम इनाम ₹1000 है।

📋 चरण-दर-चरण गाइड

  • 1. लॉगिन / रजिस्टर – अकाउंट बनाएं या मौजूदा क्रेडेंशियल से लॉगिन करें।
  • 2. बॉक्स चुनें – 10×10 ग्रिड में से किसी भी बॉक्स पर क्लिक करें। यह गोल्ड हो जाएगा और इसका 4-अंकीय कोड दिखेगा।
  • 3. भुगतान करें और खेलें – "Pick Box & Pay ₹25" बटन पर क्लिक करें। आपको QR code और UPI ID के साथ बॉक्स कोड दिखेगा।
  • 4. भुगतान करें – UPI ID कॉपी करें और PhonePe, Google Pay, या किसी भी UPI ऐप से ₹25 का भुगतान करें। भुगतान नोट में 4-अंकीय बॉक्स कोड ज़रूर डालें।
  • 5. प्रूफ जमा करें – भुगतान के बाद, "Payment Proof Submit" क्लिक करें और बॉक्स कोड, Transaction ID और UPI phone number डालें।
  • 6. इनाम जीतें – एडमिन आपके भुगतान की पुष्टि करेगा और आपका बॉक्स इनाम रिवील करेगा!
